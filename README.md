## 體例

1. **原文照錄**：底本文字一字未改。白話與註釋為今人所加，分層呈現，不與原文相混。
2. **註釋範圍**：只作三事——詞義名物制度、依據與異文、平行文獻與重出。**不作真偽價值判斷**。
3. **版本對照**：各書附錄載大正藏校勘記與 CBETA 校訂，逐條照錄；正文中之方括號短號即其行內標記。
4. **結構性文字**（卷首目次、卷題、部類標題）照錄原文而不另出白話；其相關說明見該條之註。
5. 單檔自足 HTML：無外部資源、可離線閱讀；內文連結（註釋上標、目次跳轉、附錄互指）皆為站內錨點。
